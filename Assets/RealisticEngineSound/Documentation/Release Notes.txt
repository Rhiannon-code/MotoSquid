Realistic Engine Sounds 2 - Pro Edition release notes:

v2.3.1
- Fixed an issue where the Master Volume was not correctly applied to engine prefabs.
----------------------------------------
v2.3.0
- The asset's default Unity Editor version is now set to Unity 6.0, but it can still be used with older versions of Unity.
- The asset's default render pipeline is now set to URP.
- The asset's default input system is now set to the new Input System.
- Updated the demo scene scripts to support the new Input System.
- Fixed an issue in the prefab tester demo scene where the Aggressiveness SFX UI value was not updated to the current value.
- Fixed the Pitch Multiplier UI value in the prefab tester demo scene to round to two decimal places.
- Fixed an issue with RCCP compatibility where, after the RCCP car's engine was turned off and then back on, the RES2 engine sound prefab remained off.
- Fixed an issue where changing an engine prefab's Master Volume had no effect on the Wind SFX volume.
- Fixed an issue with the i6_German_free sound pack where the engine sound would randomly cut out for a moment.
- Fixed an issue with the Supercharger Sound Controller where the sound continued playing after the RES2 script was disabled.
- Moved the wind SFX Audio Source into the "Audio Sources Unfiltered" GameObject for improved results.
- Redesigned and fine-tuned parts of the distance acoustics system for more realistic sound attenuation over distance.
- Redesigned Engine Load feature for more realistic engine load behavior. Engine audio now responds more dynamically to changes in engine workload, resulting in more natural sound variation during acceleration, gear changes, and high-RPM operation.
- Redesigned the RES2 custom editor with a fresh look by introducing a new color palette.
- Supercharger load now responds to engine workload.
- Straight Cut Gearbox load now responds to engine workload.
- City Car Gearbox load now responds to engine workload.
- Minor performance optimization to the editor script.
- Minor text and naming improvements to the editor script.
- Improved the Reverse Gear SFX pitch in all engine sound prefabs.
- Set the Current RPM and Current Speed values of all engine prefabs to 0 by default to prevent brief unwanted engine sounds at startup.
- Set the Minimum Distance default value to 1.5, engine sounds can now become louder under heavier load.
- Set the Wind Master Volume's default value to 0.7 to make the wind sound less dominant in the overall mix.
- Updated RCCP compatibility to support the latest version of RCCP.
- Updated RCC compatibility to support the latest version of RCC.
- Updated Documentation.pdf
- Experimental: Added SKILL.md file to help AI agents add RES2 prefabs to vehicles.
----------------------------------------
v2.2.0
- Added Distance Acoustics feature, which dynamically adjusts audio effects based on the distance between the vehicle and the listener to create a more realistic sense of space and environmental acoustics.
- Added Intake SFX feature to the engine sound controller (can be heard in HQ prefabs when the camera is facing the front of the vehicle engine, and also in interior mode).
- Added 200 WAV files for Intake SFX (100 for exterior view and 100 for interior view - each engine sound pack includes 4 intake SFX WAV files).
- Added 10 WAV files for Intake "Open" SFX (used universaly by all engine sound packs).
- Completely remade the Engine Sound Tester demo scenes with a much more realistic engine RPM simulation and unique RPM behavior for different vehicle types.
- Improved interior prefabs' spread effect
- Gear-shifting SFX now bypasses reverb zones for added realism.
- Minor pitch adjustments to the Bike_600ccm_HQ prefab for improved sound quality.
- Minor pitch adjustments to the Boxer_Japanese_1_HQ prefab for improved sound quality.
- Minor pitch adjustments to the Rotary_x3_HQ prefab for improved sound quality.
- Repolished multiple exterior sound clips in the Boxer_German engine sound pack.
- Repolished multiple exterior sound clips in the i6_German_Sport_3 engine sound pack.
- Fixed an issue where the engine "Shake FX" simulation was affected by the game's framerate and did not produce the desired result.
- Updated Documentation.pdf
