# Install Notes

The "EasyRoads3D.v3.3b23 - Code + Demo Scene Assets" package includes all the v3.3 beta assets including the v3.3 beta demo scene for Unity 6 in /Assets/EasyRoads3D scenes/

When the full v3.3 beta package was already imported previously and new beta demo scene specific assets are not required, only the "EasyRoads3D.v3.3b23 - Code Update" package can be imported

Package: "UI Update - EasyRoads3D.v3.3b21" - when only importing the code update and upgrading older beta code installs the "UI Update - EasyRoads3D.v3.3b21" package is also required, this package includes new UI related assets introduced in beta 21.


# URP & HDRP Notes - Pink Materials

The Multi-Lane URP and HDRP packages include render pipeline specific shaders of the new multi-lane shader in v3.3, the URP and HDRP packages with these version specific shaders should be imported manually when required

The Beta Demo scene includes the Rock Tunnel side object from the EasyRoads3D Demo Project. The URP and HDRP Tunnel shaders are located in the respective URP / HDRP SRP packages with DEMO in the name. These packages are located in the /EasyRoads3D/SRP Support Packages/ folder in the free EasyRoads3D Demo Project package on the Asset Store, https://assetstore.unity.com/packages/tools/terrain/easyroads3d-demo-project-105045  

Remaining pink materials in the beta Demo scene can be fixed by running the Unity Render Pipeline Conversion tool
